Privacy Policy

This page describes the private Google Cloud project n8n-shrub, used only by its owner with n8n.

Who this is for

This is a personal automation project. It is not a public product and is not offered to other users.

What data is accessed

The project may access Google account data that the owner authorizes through Google OAuth, such as Google Sheets, Drive, Gmail, Calendar, or other Google APIs enabled in the project.

How data is used

  • Data is used only to run the owner's own n8n workflows.
  • Data is not sold.
  • Data is not used for advertising.
  • Data is not shared with third parties except as needed to run n8n on the owner's own instance.

Storage

Any tokens or workflow data stay on the owner's n8n instance and Google Cloud project. They are not published.

Access and revocation

Google account access can be revoked at any time in Google Account settings under third-party apps with account access.
